### 4. 🛒 Приложение по заказу продуктов (API)

**Объект:** API интернет-магазина (наборы, корзина, доставка).

**Что тестировал (123 проверки):**

| Метод | Что проверял |
|-------|--------------|
| POST /api/v1/kits/{id}/products | id и quantity продукта, productsList |
| POST /fast-delivery/.../calculate-delivery.xml | количество, вес, время доставки |
| PUT /api/v1/orders/{id} | добавление в корзину |
| GET /api/v1/orders/{id} | получение корзины |
| DELETE /api/v1/orders/{id} | удаление корзины |

**Результаты:** 123 проверки, 37 багов

**Найденные проблемы:**
- API возвращает 200 OK вместо 400 Bad Request при некорректных данных
- 500 Internal Server Error при невалидных типах
- DELETE возвращает 404 вместо 200

**Техники:** классы эквивалентности, граничные значения, негативное тестирование, проверка типов данных

**Артефакты:** [API-чек-лист и баг-репорты](https://github.com/Nikkerru/qa_projects_practicum/blob/main/product_custom_delivery.xlsx)
